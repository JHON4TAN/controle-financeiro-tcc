💰 Sistema de Controle Financeiro Pessoal

Projeto desenvolvido como Trabalho de Conclusão de Curso (TCC) do curso de Análise e Desenvolvimento de Sistemas.

O sistema tem como objetivo auxiliar usuários no gerenciamento financeiro pessoal através de:

controle de receitas e despesas
categorização de gastos
metas financeiras
relatórios
gráficos interativos
dashboard visual


🚀 Tecnologias Utilizadas
Frontend
React.js
Vite
Tailwind CSS
Recharts
Lucide React
Backend
Node.js
Express
Banco de Dados
PostgreSQL


📊 Funcionalidades
Sistema de autenticação
Cadastro de receitas
Cadastro de despesas
Gerenciamento de categorias
Dashboard financeiro
Relatórios financeiros
Gráficos interativos
Metas financeiras
Perfil do usuário

public/

▶️ Como Executar o Projeto
Clonar o repositório
git clone https://github.com/JHON4TAN/controle-financeiro-tcc.git
Instalar dependências
npm install
Executar frontend
npm run dev
Executar backend
npm start
